# Grão em Grão - Agendamento

MVP de agendamento para a clínica de fisioterapia infantil Grão em Grão, em Mogi das Cruzes.

## Problema
Comunicação lenta e controle de agenda feito em planilhas.

## Solução
Sistema de agendamento de consultas com contato via WhatsApp.

## Tecnologias
- Python 3 com Flask
- SQLite (banco de dados)
- pytest (testes automatizados)
- GitHub Actions (integração contínua)


## Como rodar
1. Clone o repositório: `git clone https://github.com/PauloCosta111/grao-em-grao-agendamento.git`
2. Instale as dependências: `pip install -r requirements.txt`
3. Execute o projeto: `python app.py`


## Como rodar os testes
Execute `pytest` na pasta do projeto.
